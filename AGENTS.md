# AGENTS.md

Guidance for AI agents (and the people who run them) working on `meritum-docs`, the documentation site of Meritum. The site is built with [Zensical](https://zensical.org) from `docs/` and deployed to Cloudflare Pages (README).

## Rules for every article

1. **Write, then humanize.** Every article, and every change to an article's prose, is written first and then passed through the `humanizer` skill in `.claude/skills/humanizer/` (embedded mode: keep only the final text). Only the humanized text goes into a commit. Keep Polish typography: „” quotes, en dash in ranges such as A–J; no em dashes in prose.
2. **The design system wins.** Anything visual (CSS, HTML components in Markdown, Mermaid styling, icons, colours, fonts) follows the Meritum design system: `DESIGN_SYSTEM.md` and `tokens/meritum.css` in meritum-design-system, and the `meritum-ui` skill in meritum-monorepo (`.claude/skills/meritum-ui/SKILL.md`). It takes precedence over any other style choice, including Zensical defaults and other design skills. Colours come only from the tokens copied into `docs/assets/stylesheets/meritum.css`; verdict words and hints come from `copy/pl.json`; red appears only with „Fałszywe”; no gradients, purple, glass, side stripes on cards or uppercase eyebrow labels.
3. **Facts come from sources, never from memory.** Every statement about Meritum comes from the product document (`design-system/docs/product-doc.html`, generated by `gen_product_doc.py`), `PRODUCT.md` and `DESIGN_SYSTEM.md` in meritum-design-system, the repos' READMEs and `docs/architecture.md`, or core's contracts. Nothing is invented: no numbers, results, partners, sources or quotes. Planned features are described as planned. When sources disagree, the product document wins over READMEs for intent, and the code repos win for what exists today.

## Hand-written and generated pages

| Pages | Who writes them |
|---|---|
| `docs/adr/*.md`, `docs/slownik.md` | `scripts/generate.py` from the product document |
| `docs/referencja/kontrakty.md` | `scripts/generate.py` from `contracts/meritum.schema.json` in meritum-core |
| `docs/architektura/repozytoria.md` | `scripts/generate.py` from the GitHub org |
| everything else in `docs/` | people and agents, by hand |

Generated pages start with the marker comment `Wygenerowane przez scripts/generate.py`. Never edit them by hand: the daily refresh (`.github/workflows/refresh.yml`) overwrites them. Fix the source instead. The generator refuses to overwrite a file without the marker, so hand-written articles are never touched. Do not add the marker to a hand-written page.

## Working on the site

```bash
uv sync
uv run zensical serve                 # http://localhost:8000
uv run zensical build --strict        # what CI runs; warnings, broken links and anchors fail it
uv run python scripts/test_generate.py
```

- Navigation is explicit in `zensical.toml` (`nav`). A new article needs a nav entry. ADR pages are reached from `adr/index.md` and are not listed one by one.
- Diagrams are Mermaid fences (`` ```mermaid ``). Use flowcharts and sequence diagrams, which the theme colours from the tokens; check that they render in light and dark mode.
- Icons: Lucide in front matter (`icon: lucide/...`) and inline (`:lucide-name:`), used as signs next to words, never alone and never as icon-tile grids.
- Links between pages are relative `.md` links, so the strict build checks them.

## Git

- Branches: `main` (production site) and `develop` (preview). Changes go through a PR to `develop`; a human promotes `develop` to `main`. Never push to `develop` or `main`.
- Commit messages, PR titles and descriptions are in Polish and pass through the `humanizer` skill before `git commit` or `gh pr create`.
- No AI attribution anywhere: no `Co-Authored-By` for an AI, no "Generated with", no robot emoji, no session links.
- No secrets in the repo. CI uses repo secrets only (the org is on the Free plan): `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `MERITUM_BOT_TOKEN`.
- No e2e or cross-component tests in CI; the docs CI is the strict build.
